\section{设计流程}
\label{sec:intro}

题目要求完成词频统计、带词干化的倒排索引、单词与短语查询，以及查询阈值实验。
这些工作不能彼此分离：停用词改变位置编号，词干化改变词项，查询又必须复用建索引时的
规范化规则。项目因此按“语料收集、词频统计、停用词选择、词干化、倒排索引、词典结构、
外部构建、查询”的顺序展开，每一阶段都留下可重跑的命令和输出。% src: 本轮任务复跑

系统的总数据流如图~\ref{fig:pipeline}：预处理阶段使用 Python 把 HTML 转成文本层，再交由
C++ 进行处理；切词后的 token 同时进入统计与索引两条路径；查询侧按索引头
记录的 flags 重放停用词与词干化步骤。这样可以把网页解析错误、统计口径错误和索引错误
分开定位。% src: F1、F3、P1

\subsection{语料收集}

\subsubsection{语料来源}
\label{sec:corpus}

主语料取自 MIT Shakespeare 站点~\cite{shakespeare} 及其官方 GitHub 镜像。
仓库中同时存在现行小写作品目录、旧版大写分类目录和
Moby 纯文本版本，我们以 MIT Shakespeare 站点首页的目录作为作品清单。% src: F1、F3、F41

\subsubsection{预处理与切词}
\label{sec:preprocess}

\code{tools/extract.py} 把每个 HTML 页面转换成“一行一个语义单元”的文本文件，
同时生成 \code{manifest.tsv} 作为整个语料的文档目录和映射表。% src: P1

考虑到语料为英文，因此切词器把“连续 ASCII 字母并允许内部撇号”的极大串定义为 token。\code{don't} 与
\code{o'er} 保持为一个词，行首撇号被丢弃（例如\code{'Tis}$\to$\code{tis}），行尾撇号
作为分隔（例如\code{friends'}$\to$\code{friends}）；连字符、数字和普通标点均为分隔符（例如\code{to-day}$\to$\code{to,day}，\code{1660s}$\to$\code{s}）。所有 token
均进行小写化。

\subsubsection{特殊情况处理}
\label{sec:preprocess-analysis}

处理过程中经过检验发现，莎士比亚语料中存在一些特殊情况：
\paragraph{舞台提示格式不统一} 例如 Moby 版把内嵌舞台提示写成方括号。

\paragraph{HTML 文件本身标签残缺} 例如 \code{Poetry/elegy.html} 中 \code{</TITLE\n</HEAD>} 由于缺少闭合尖括号而导致读取失败。

我们都进行了额外的判定。
